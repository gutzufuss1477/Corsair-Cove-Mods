# Corsair Cove QoL Trainer

14 optional tweaks: faster carriers, ships and building, camp range and housing, 6/9-good warehouses, longer bridges, more routes, overlapping camps, persistent exploration, coastal attack control and separate hull/crew/supplies protection in dice encounters. Single-EXE setup, resizable UI, 12 languages.
